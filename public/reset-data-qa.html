Bersihkan Data Browser Aplikasi Ini

Halaman alat QA/pemulihan. Tombol di bawah menghapus seluruh data aplikasi yang tersimpan di browser INI (IndexedDB, localStorage, cache, service worker) untuk alamat ini — sama seperti "Clear site data". Data di server (SQLite) dan di browser/perangkat lain tidak terpengaruh.

⚠️ Hanya gunakan pada browser uji/QA atau bila memang ingin memulai dari data contoh bawaan. Pada instalasi berisi data asli, gunakan menu Backup & Restore di dalam aplikasi.
